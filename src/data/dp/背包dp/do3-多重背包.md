# 多重背包
有N种物品和一个容量为V的背包。第i种物品最多有n[i]件可用，每件费用是c[i]，价值是w[i]。求解将哪些物品装入背包可使这些物品的费用总和不超过背包容量，且价值总和最大。

# 状态转义方程
这题目和完全背包问题很类似。
- dp[i][v] 代表前i件物品，最大容量为v时获得的最大价值
- dp[i][v] = max(dp[i - 1][v - k * c[i]] + k*w[i])  0  <= k <=n[i]

# 朴素解法
二维数组写法
```
    dp[0][0] = 0
    for i = 1...N {
        for v= 1...V{
            for k=1...min(n[i], v/c[i]) {
                dp[i][v] = max(dp[i][v],dp[i - 1][v - k*[c[i]]] + k * w[i])
            } 
        }
    }
```
一维数组写法(必会)
```
    dp[0] = 0 
    for i := 1; i <= N; i ++{
        for v := V;v >= c[i]; v -- {
            for k := 1; k <=n[i] && k *c[i] <=j;k++ {
                dp[v] = max(dp[v],dp[v - k * c[i]] + k * w[i])
            }
        }
    }
```


# 转化为 0-1背包
- 由于每种物品有了限制次数 其实可以把其看成多个物品 每个物品最多取一个 这样就成了0-1背包问题
- 背包体积做优化，比如当物品的数量很多并且超过了背包容量的时候，我们可以把超过容量的数量去掉，
- 但是整体的复杂度还是很高。 尤其是当我们背包容量很大的时候。


#  二进制表示法
- 每一个数都可以用二进制来表示，所以我们可以把每个物品的数量n拆解成一些数(a1,a2,a3...at)，而这些数的组合可以表示1-n中的任意一个数。
- 我们以11为例，我们把11拆解成1,2,4,4这四个数，我们可以发现1-11中的任意一个数都可以用这些数的组合来表示。
 - 拆分具体实现：不能全部拆成2的倍数，而是先按2的倍数从小到大拆，最后是一个小于等于最大倍数的余数。
 - 例如 25，把它拆成**1、2、4、8**、10，最后是余数10（25 - 1 -2-4-8），10 < 16 = 24，可以验证用这5个数能组合成1~25内的所有数字，不会超过25。如果把25拆成1、2、4、8、16，相加的范围就是[1, 31]了。
   
二进制表示法实现
```
    //重新定义
    new_c = []
    new_w = []
    new_n = 0
    
    //二进制表示法
    for i := 1; i < N; i ++ { //遍历物品
        sum := n[i]  //sum代表物品的最多取值
        k := 1
        for k := 1; sum >= k; k <<= 1{
            new_c  = append(new_c,k *c[i])
            new_w  = append(new_w,k *w[i])
            new_n++
            sum -= k
        }
        if sum > 0 {
            //最后剩余的
            new_c = append(new_c,sum *c[i])
            new_w = append(new_w,sum *w[i])
            new_n++
        }
    }
    
    //0-1背包
    dp[0] = 0
    for i := 0; i < new_n; i ++ {
        for v:=V; v >= c[i]; v-- {
            dp[v] = max(dp[v],dp[v-c[i]] + w[i])
        }
    }
    return dp[V]
```
